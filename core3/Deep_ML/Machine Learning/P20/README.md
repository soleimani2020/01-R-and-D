# Calculate Accuracy Score

## Description

Write a Python function to calculate the **accuracy score** of a model's predictions.

The function takes:

- `y_true`: 1D NumPy array containing the true labels
- `y_pred`: 1D NumPy array containing the predicted labels

It returns:

- Accuracy score as a `float`

Accuracy is calculated as:

\[
\text{Accuracy} = \frac{\text{Number of Correct Predictions}}{\text{Total Number of Predictions}}
\]
