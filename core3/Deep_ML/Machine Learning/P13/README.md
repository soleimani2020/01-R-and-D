# Descriptive Statistics Calculator

**Difficulty:** Easy
**Topic:** Statistics

Write a Python function that calculates common descriptive statistics for a numerical dataset.

## Metrics

The function returns:

* `mean` — average value
* `median` — middle value
* `mode` — most frequent value
* `variance` — population variance
* `standard_deviation` — square root of variance
* `25th_percentile` — first quartile (Q1)
* `50th_percentile` — median (Q2)
* `75th_percentile` — third quartile (Q3)
* `interquartile_range` — Q3 − Q1



## Example

```python
data = [1, 2, 2, 3, 4, 5]

descriptive_statistics(data)
```
