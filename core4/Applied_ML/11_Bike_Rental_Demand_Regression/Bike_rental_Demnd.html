Bike Rental Demand Prediction with Regression Models¶

Project 03 · Supervised Learning · Regression

Objective¶

Predict hourly bike rental demand using calendar, time, and weather-related features. The workflow covers data inspection, exploratory analysis, chronological train/test splitting, preprocessing, model training, evaluation, and Ridge Regression hyperparameter tuning.

Target variable: cnt — total number of bike rentals in an hour.

Evaluation approach: The data is kept in chronological order, and the final 20% is held out for testing.

5. Prepare features and target¶

  • Exclude casual and registered because they directly contribute to cnt; including them would cause target leakage.
  • Exclude instant, which is a record index rather than a useful demand predictor.
  • Convert dteday to a datetime and sort chronologically. The existing calendar/time features are retained for modeling.
In [119]:
# Prepare data in chronological order

8. Handle missing values¶

Fit imputation values using the training set only, then apply those same values to the test set:

  • Numerical features: replace missing values with the training-set mean.
  • Categorical features: replace missing values with the training-set mode.

This dataset has no missing values in the original data, but the steps make the preprocessing explicit and robust.

In [122]:
# Find numeric and categorical columns
# numeric_features = X_train.select_dtypes(include=["number"]).columns

# Define categorical and numerical features manually
categorical_features = [
    "season", "mnth", "hr", "weekday", "weathersit"
]

numeric_features = [
    "yr", "holiday", "workingday",
    "temp", "atemp", "hum", "windspeed"
]

# Fill missing numerical values using the mean
for col in numeric_features:
    mean = X_train[col].mean()
    X_train[col] = X_train[col].fillna(mean)
    X_test[col] = X_test[col].fillna(mean)

# Fill missing categorical values using the mode
for col in categorical_features:
    mode = X_train[col].mode()[0]
    X_train[col] = X_train[col].fillna(mode)
    X_test[col] = X_test[col].fillna(mode)

# Verify missing values in selected features

13. Evaluate all three regression models¶

In [129]:
from sklearn.metrics import mean_absolute_error, mean_squared_error, r2_score


# Store trained models and their predictions
models = {
    "Linear Regression": (model_LR, y_pred_LR),
    "Ridge Regression": (model_Ridge, y_pred_Ridge),
    "Elastic Net": (model_ElasticNet, y_pred_ElasticNet)
}

# Calculate evaluation metrics
results = []

for name, (model, predictions) in models.items():
    mae = mean_absolute_error(y_test, predictions)
    rmse = np.sqrt(mean_squared_error(y_test, predictions))
    r2 = r2_score(y_test, predictions)

    results.append({
        "Model": name,
        "MAE": mae,
        "RMSE": rmse,
        "R-squared": r2
    })

# Display the results
results_df = pd.DataFrame(results)
display(results_df.round(3))

Comparison of baseline models¶

Based on the held-out test set:

  1. Linear Regression: MAE = 98.798, RMSE = 133.835, and R² = 0.632. It has the lowest error among these three baseline models.
  2. Ridge Regression: MAE = 98.875, RMSE = 133.910, and R² = 0.631. Its performance is almost identical to Linear Regression.
  3. Elastic Net: MAE = 121.827, RMSE = 163.621, and R² = 0.449. It performs worse on this split.

Conclusion: Linear Regression performs slightly better than the other baseline models. Linear and Ridge Regression explain approximately 63% of the variation in hourly rental counts on the test set.

14. Tune Ridge Regression with GridSearchCV¶

Use time-series cross-validation to compare Ridge alpha values while preserving the order of observations. The preprocessing matrices were prepared before this search, so the cross-validation scores should be interpreted with that limitation in mind; a fully leakage-safe tuning workflow would place preprocessing and the estimator together in a scikit-learn Pipeline.

In [130]:
from sklearn.linear_model import Ridge
from sklearn.model_selection import GridSearchCV, TimeSeriesSplit

tscv = TimeSeriesSplit(n_splits=5)

param_grid = {
    "alpha": [0.01, 0.1, 1, 10, 100, 1000]
}

grid_search = GridSearchCV(
    estimator=Ridge(),
    param_grid=param_grid,
    cv=tscv,
    scoring="neg_root_mean_squared_error"
)

grid_search.fit(X_train_final, y_train)

print("Best alpha:", grid_search.best_params_["alpha"])
print("Best CV RMSE:", round(-grid_search.best_score_, 3))

Short Analysis¶

The tuned Ridge model's test performance is almost identical to the baseline Linear and Ridge Regression models. The MAE indicates an average absolute prediction error of about 99 rentals per hour. The R² score means the model explains approximately 63.2% of the variation in rental counts in this test set.

Conclusion¶

The tested alpha values did not produce a meaningful improvement over the baseline models on the held-out test data. Further work could compare nonlinear models and use a preprocessing pipeline during cross-validation. Because rental counts cannot be negative, also check whether the model produces negative predictions before using its outputs operationally.
