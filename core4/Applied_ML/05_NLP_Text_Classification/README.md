# Dimensionality Reduction for Human Activity Recognition

## Overview
This project explores feature selection and dimensionality reduction for a human activity recognition classification task. The dataset contains smartphone sensor measurements collected from 30 volunteers performing six different physical activities.

The objective is to predict the activity performed using 562 explanatory variables while reducing the dimensionality of the dataset.

## Objectives
- Explore and prepare the dataset.
- Investigate methods for selecting relevant features.
- Apply dimensionality reduction techniques.
- Evaluate the impact of dimensionality reduction on classification performance.
- Compare model performance before and after reducing the number of features.

## Dataset
The dataset contains observations from six activities:
- Walking
- Walking upstairs
- Walking downstairs
- Sitting
- Standing
- Lying down

The explanatory variables are derived from smartphone sensor measurements and mathematical transformations.

## Methods
- Exploratory data analysis
- Feature selection
- Dimensionality reduction
- Classification
- Model evaluation and comparison
