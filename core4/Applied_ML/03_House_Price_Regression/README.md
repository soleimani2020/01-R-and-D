# 03_House Price Prediction with Regression

## 🔍 Overview
This project applies **supervised machine learning regression techniques** to predict house sale prices based on property characteristics. Using the Ames Housing dataset, the project explores data preprocessing, feature engineering, neural network modeling, and performance evaluation.

## 🎯 Objectives
- 🧹 Explore, clean, and preprocess the housing dataset.
- 📊 Analyze relationships between property features and sale prices.
- ⚙️ Prepare numerical and categorical features for model training.
- 🧠 Build and train a regression model using TensorFlow / Keras.
- 📈 Evaluate prediction performance using appropriate regression metrics.
- 🔎 Compare predicted prices with actual sale prices to assess model performance.

## ⚙️ Methods
- 🧭 Exploratory data analysis (EDA)
- 🧹 Data cleaning and preprocessing
- 🔢 Numerical feature scaling and categorical feature encoding
- 🧠 Neural network regression with Keras
- 🛑 Early stopping to help prevent overfitting
- 📉 Model evaluation using **MAE, MSE, RMSE, and R²**
- 📊 Visualization of training progress and predicted versus actual prices

## 🛠️ Technologies
- 🐍 **Python** — programming and data analysis
- 🐼 **Pandas** — data manipulation and preprocessing
- 🔢 **NumPy** — numerical computation
- 🧠 **TensorFlow / Keras** — neural network development
- 📊 **Matplotlib** — data visualization
- 🤖 **Scikit-learn** — preprocessing and evaluation metrics
