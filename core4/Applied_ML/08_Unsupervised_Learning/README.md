# Text Mining and Sentiment Analysis of Political Speeches

## Overview
This project applies text mining and natural language processing (NLP) techniques to political speeches by Donald Trump. The first part focuses on cleaning and processing text data to generate a word cloud. The second part develops a machine learning model to perform sentiment analysis on individual speech paragraphs.

## Objectives
- Clean and preprocess text using regular expressions.
- Tokenize text and remove stop words.
- Explore word frequencies and visualize prominent terms using word clouds.
- Prepare text data for machine learning.
- Build and evaluate a sentiment classification model.

## Methods
- Text preprocessing and normalization
- Regular expressions and tokenization
- Stop word removal
- Word frequency analysis
- Word cloud visualization
- Natural Language Processing (NLP)
- Sentiment analysis and supervised classification
- Model evaluation

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- NLTK
- Scikit-learn
- WordCloud
