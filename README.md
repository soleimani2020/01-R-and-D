# SMARTINI3, Data Analysis & Machine Learning

A collection of scientific software, Python tools, and machine learning projects for **computational biophysics, molecular dynamics simulations, data analysis, and applied machine learning**.

This repository brings together my research in multiscale membrane modeling, computational methods for biomolecular systems, scientific programming, and practical machine learning applications.

---

## 📂 Repository Overview

The repository is organized into four core areas, covering specialized molecular simulation research, scientific data analysis, machine learning fundamentals, and applied machine learning projects.

## 🧩 Repository Categories

| Core | Category | Description |
|---|---|---|
| **Core1** | **SMARTINI3** | Development of an ultra-coarse-grained (UCG) membrane model designed to balance computational efficiency and biophysical realism. The model is systematically parameterized using unsupervised learning and multi-objective evolutionary algorithms. |
| **Core2** | **Data Analysis** | Python tools and scripts for analyzing molecular dynamics simulations, with a focus on membranes, proteins, water, and other biomolecular systems. |
| **Core3** | **Deep Learning & Machine Learning Fundamentals** | Python implementations and solutions covering linear algebra, statistics, classical machine learning, and deep learning. |
| **Core4** | **Applied Machine Learning Projects** | Practical projects covering exploratory data analysis, classification, regression, deep learning, natural language processing (NLP), computer vision, time-series forecasting, unsupervised learning, model evaluation and optimization, and scientific machine learning. |

---

## 🔬 Research & Technical Interests

- **Computational Biophysics:** Multiscale modeling of membranes and biomolecular systems.
- **Molecular Dynamics:** Simulation workflows, analysis methods, and coarse-grained modeling.
- **Scientific Computing:** Numerical methods, algorithm development, and Python-based scientific tools.
- **Data Science & Machine Learning:** Data preprocessing, feature engineering, model development, evaluation, and optimization.
- **Deep Learning & AI:** Neural networks, deep learning architectures, and practical AI applications.
- **Scientific Machine Learning:** Connecting machine learning with physical modeling, simulation, and scientific data.
